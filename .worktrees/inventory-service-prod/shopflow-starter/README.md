# shopflow-starter (placeholder)

**This module is a skeleton, not a working application.** It is the generated Spring Boot application
with one `contextLoads()` test and no code of its own. Nothing in `docs/` or in the other modules uses it.

It stays in the reactor so that the parent build keeps checking that a new module of this kind compiles
and starts. The cost is a few seconds of CI time. If no purpose is found for it, remove the module from
the `<modules>` list in the parent `pom.xml` and delete the directory.
